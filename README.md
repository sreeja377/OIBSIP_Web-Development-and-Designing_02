# Personal Portfolio Website

## 📌 Project Overview

This project is a modern and responsive Personal Portfolio Website developed using HTML and CSS. The website showcases personal information, technical skills, projects, resume, and contact details in a professional and visually appealing format.

The portfolio serves as an online presence for displaying skills, achievements, and project work.

---

## 🎯 Objective

The objective of this project is to create a professional portfolio website that:

* Introduces the developer
* Highlights technical skills
* Showcases project work
* Provides resume access
* Displays contact information
* Demonstrates frontend web development skills

---

## 🛠 Technologies Used

* HTML5
* CSS3
* Google Fonts
* Responsive Web Design

---

## ✨ Features

* Modern Hero Section
* Professional Navigation Bar
* About Me Section
* Skills Section with Progress Bars
* Projects Showcase Section
* Resume Download/View Option
* Contact Information Section
* Responsive Design for Mobile and Desktop
* Hover Effects and Smooth UI
